# 변경 검증 근거 보고서

> 이식 구분: 복붙 가능. 빈 양식 그대로 복사해서 작업별로 채운다.

기능 이관, 업무 규칙/권한 변경, API·DB 변경 등 완료 근거를 남길 필요가 있을 때 사용한다. 적용되지 않는 항목은 생략하거나 `N/A`로 표시한다. 민감정보와 운영 비밀값은 기록하지 않는다.

Acceptance가 "무엇을 만족해야 완료인가"를 정의한다면, Evidence는 "실제로 만족했다는 근거가 무엇인가"를 기록한다.

- [ ] 요구사항 및 관련 Acceptance Criteria를 확인했다.
- [ ] 필요한 테스트를 수행하고 실제 결과를 기록했다.
