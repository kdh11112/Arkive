# 프로젝트 지식 템플릿 팩 (복붙용)

> 대상 프로젝트에는 **이 파일 하나만** 복사한다.
> `docs/ai/project/`의 Arkive 문서는 현재 지식 기록이므로 복사하지 않는다.
> 각 절을 `docs/ai/project/<이름>.md`로 나눠 저장해도 되고, 이 파일 하나로 유지해도 된다.
> 확인되지 않은 값은 추측하지 말고 `미확인`과 확인 담당자를 적는다.

각 문서 첫 부분에는 아래 상태 주석을 붙인다.

```html
<!--
문서 상태: 미확인
미완성 항목:
필요한 근거/확인자:
완성 방법:
완료 기준:
-->
```

## 작성 순서

1. `pom.xml`·설정 파일에서 기술 스택과 DB를 확인한다.
2. 대표 기능 1개를 `화면 → Controller → Service → Mapper → XML → DB`로 추적한다.
3. 확인된 값만 표에 적고, 나머지는 `미확인`과 확인 담당자를 남긴다.
4. 기능을 추가할 때마다 3·5·6·7번 표를 갱신한다.
