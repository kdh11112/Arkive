# 회귀 테스트 체크리스트

> 이식 구분: 복붙 가능(양식). 파일째 복사해서 항목대로 찍는다. 해당 없는 항목은 N/A로 둔다.

## 업무 기능
- [ ] 정상 입력 결과 확인
- [ ] 경계값과 기준점 전후 확인
- [ ] null, 빈 문자열, 빈 목록 확인
- [ ] 중복/재요청/이미 처리된 상태 확인
- [ ] 권한 없는 접근 및 잘못된 상태 전이 확인
- [ ] 기존 화면 표시, 메시지, API 계약에 회귀 없음

## Mapper / DB
- [ ] 변경된 Mapper SQL이 PostgreSQL에서 실행됨
- [ ] 동적 if/choose/foreach 분기 확인
- [ ] 0건/1건/다건 및 NULL 결과 확인
- [ ] 조인/집계/정렬/페이징 결과 확인
- [ ] 트랜잭션 롤백과 테스트 데이터 정리 확인
- [ ] 운영 DB 접속 정보가 테스트 설정에 없음

## 품질
- [ ] 관련 기존 테스트 실행
- [ ] 프로젝트의 전체 검증 명령 실행
- [ ] JaCoCo 보고서 확인
- [ ] 실패를 숨기기 위해 테스트를 삭제/skip하지 않음
- [ ] 미실행 항목과 잔여 위험 기록
