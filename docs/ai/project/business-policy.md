# 업무 정책 및 권한 (가이드형 템플릿)

> 이식 구분: 가이드형 템플릿. 새 프로젝트에 복사한 뒤 양식만 채운다. 코드만 보고 추론하지 말고 담당자 확인을 근거로 적는다.

> 현재 저장소에서 확인한 코드만으로 Arkive의 완전한 업무 정책이나 권한 모델을 확정할 수 없다. 업무 규칙을 추측해 채우지 않는다.

## 작성 예시 (Arkive) — 아래는 참고용

## 현황 (Arkive 예시)

- 기능별 상태 전이, 사용자 역할, 권한 부여 기준: 미확인
- 메뉴 테이블의 `grad`, `use_yn` 등의 실제 업무 의미: 코드와 초기 데이터만으로 확정 불가
- 신청·승인·삭제 등 업무 정책: 미확인
- 담당자 승인 또는 근거 문서: 미확인

업무 담당자의 확인 또는 승인된 요구사항을 근거로 기록한다. 기술 구현만 보고 정책을 역추론하지 않는다. 변경 시 [acceptance-template.md](../common/acceptance-template.md)의 조건과 연결한다.
