# 오류 처리 및 코드 체계 (가이드형 템플릿)

> 이식 구분: 가이드형 템플릿. 새 프로젝트에 복사한 뒤 양식만 채운다. 중앙 코드체계 없으면 없다고 명시한다.

> 현재 확인 범위에서 프로젝트 전체에 적용되는 단일 오류 코드 레지스트리를 확인하지 못했다. 기존 메시지 키, 응답 값, HTTP 상태를 통일된 Error Code라고 추정하지 않는다.

## 확인된 처리 구성 (Arkive 예시)

- eGovFrame 예외 처리 클래스가 `egovframework.example.exception` 아래 존재한다.
- 시스템 Controller는 JSON 응답에서 `result` 값을 반환하는 코드가 있다. 전체 오류 응답 계약은 미확인이다.
- 한국어/영어 메시지 리소스 파일이 `src/main/resources/egovframework/message/`에 있다.
- API/메시지의 오류 코드 정의, 노출 정책, HTTP 상태 매핑, 재시도 기준과 로그 상관 ID: 미확인.

## 오류 계약 등록 양식

| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

오류 체계를 새로 추가하거나 변경할 때는 API 호출자와 화면 사용처, 다국어 메시지, 모니터링 및 개인정보 로그 정책을 확인한다. 프로젝트 담당자 승인 없이 새 코드 체계를 단정하지 않는다.
